# ludens-privacy

Music Ludens 앱들의 개인정보처리방침 페이지입니다. GitHub Pages로 공개됩니다.

- 목록: https://michaelyom.github.io/ludens-privacy/
- ludensTuner: https://michaelyom.github.io/ludens-privacy/ludenstuner/
- ludensPiano: https://michaelyom.github.io/ludens-privacy/ludenspiano/

## 새 앱 추가

1. `<앱이름>/index.html` 폴더를 만듭니다 (기존 `ludenstuner/index.html`을 복사해 고치면 됩니다).
2. 루트 `index.html` 목록에 링크를 한 줄 추가합니다.
3. 커밋하고 푸시하면 1–2분 뒤 `https://michaelyom.github.io/ludens-privacy/<앱이름>/`에 반영됩니다.

스토어에 등록한 URL은 바뀌면 안 되므로, 폴더 이름은 한 번 정하면 그대로 둡니다.
